- **Game / Chat digits roll independently.** Increasing values roll upward and
  decreasing values roll downward. Only changed digits move: changing 20 to 25
  leaves the 2 still, while changing 25 to 30 rolls both digits.
- **Quick direction changes stay smooth.** Each digit continues from its current
  position when the wheel reverses, without queuing old readings. The separator
  never rolls and the numbers no longer fade.
- **A curved odometer motion.** Digits gently compress as they rotate out of view
  instead of being cut off by a hard edge. Text stays the same size at 0 and 100,
  with smooth spacing as digits enter and leave the readout.

Retains the rendering and window-update performance improvements from 1.0.4.
Animation timers stop when idle; headset queries and commands are unchanged.
