- **Connection reminders clear automatically.** If you try a control while the
  headset is unavailable, the reconnect reminder now disappears as soon as live
  readings return. You no longer need to click the overlay to dismiss it.
- **Other errors stay visible.** Reconnecting does not dismiss unrelated settings
  save errors or unconfirmed EQ changes.
- **Windows connection troubleshooting.** The user guide now links to Audeze's
  Phone Service workaround for repeated dongle disconnects.

Polling speed and background USB traffic are unchanged. This update fixes a stale
message; it does not change headset firmware or Windows services.
