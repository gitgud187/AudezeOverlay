- **More reliable tray icon at sign-in.** If Windows Explorer is still starting,
  the overlay retries adding its tray icon briefly. Retries stop as soon as the
  icon is registered, with no permanent background timer.
- **Tray recovery after Explorer restarts.** Recreating the Windows taskbar starts
  a fresh, bounded registration attempt so the overlay can restore its icon.

Headset polling and connection timing are unchanged. This update does not add a
startup delay or change headset firmware.
